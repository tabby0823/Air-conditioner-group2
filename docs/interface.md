# 模块接口约定文档
> 本文档统一所有模块通信规则，所有人开发以此为准；改动必须更新文档 + 全员同步

## 1. TCP 雷达通信（A 模块输出人员状态）
- TCP 服务端端口：**8080**
- 报文格式：单次发送单个字符
  - `0`：无人
  - `1`：有人
- 说明：雷达连接 ESP32 TCP 服务端，持续上报 0 / 1

## 2. 固件内部人员状态变量（供 B 模块读取）
全局状态：`human_present`
- human_present = 1：有人
- human_present = 0：无人
